PHASE 4 COMPLETION REPORT
========================

AUTHORITATIVE STATUS
--------------------
FINAL_PHASE4_STATUS = COMPLETE_WITH_DOCUMENTED_LIMITATION

Phase 4 closure applies to the documented evidence-interface, selective-evidence,
verification, modality-validation, and conservative evidence-gating scope. It does
not require or claim synchronized RGB+Thermal+Radar object-level evidence for every
Caltech track. The audit matrix is results/caltech_rgb_tracking/phase4_completion_audit.csv.

DEMONSTRATED ON THE CALTECH PROJECT DATA
----------------------------------------
- RGB evidence: existing detector/tracker outputs contain 2,210 observations
  across 69 Caltech visual track IDs.
- Reliability-driven selective evidence: selection is complete for the existing
  17 UNCERTAIN tracks. Their representative early/middle/late RGB evidence is
  selected; only UNCERTAIN tracks receive these selected crops.
- Representative RGB evidence extraction: 44 selected RGB crops exist across
  those 17 tracks, and the referenced crop paths resolve.
- Semantic VLM verification: real SmolVLM-500M-Instruct integration was executed
  on selected uncertain-track evidence, with 17 existing track-level outputs.
  VLM confidence is a generated-token probability proxy, not calibrated
  probability. Caltech VLM results are exploratory and do not establish
  track-level ground-truth accuracy.
- Thermal timestamp synchronization: Track 24 has four RGB/Thermal timestamp
  matches with deltas around 4.25-4.48 ms. Other selected tracks have no matches.
- Thermal preprocessing: Thermal frame reading and normalized grayscale/
  intensity preprocessing are implemented. These values are image intensity,
  not calibrated physical temperature.
- Official Thermal size handling: the official Caltech stereo-rectification
  workflow pads native 640x512 Thermal imagery to 960x600 before paired
  rectification. This padding workflow is validated as the official procedure.
- Phase 5 compatibility and evidence gating: existing outputs cover 69 tracks
  and distinguish available, unavailable, and unassociated evidence. Existing
  tests verify that unassociated Thermal/Radar is not injected as object-level
  evidence. Missing modality evidence is not treated as negative class evidence.

DEMONSTRATED ONLY ON THE BOREAS VALIDATION SUBSET
------------------------------------------------
- Radar geometric evidence validation: PASS on the already downloaded BOREAS
  Objects-V1 3-second subset. The existing geometric-validation CSV contains
  57 associated annotation rows, representing 41 unique associated
  visual-UUID/Radar-scan pairs after consistent duplicate rows are collapsed.
- Sampled persistent visual/ground-truth UUID layer: ESTABLISHED from 15
  timestamped BOREAS 3D tracking-label frames and their nearest actual camera
  timestamps. The subset contains 48 UUIDs; 45 recur in adjacent annotated
  frames. These are sampled timestamped 3D object annotations, not
  image-space boxes or detector-generated visual tracks for every camera frame.
- Radar intensity-candidate evidence associated geometrically with persistent
  BOREAS visual/ground-truth UUIDs: ESTABLISHED. Nine UUIDs have associations
  in at least two consecutive Radar scans; the maximum consecutive run is
  three scans.
- These BOREAS associations compare extracted raw Radar intensity candidates
  with timestamped 3D ground-truth object geometry using the previously
  validated calibration, pose chain, and unchanged polar gates.
- The Radar candidate index is an ordered-list ordinal local to one scan.
  It is not a persistent Radar return/object identity; matching index values
  across scans do not imply the same physical return.
